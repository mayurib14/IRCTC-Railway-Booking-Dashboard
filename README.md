
# IRCTC Railway Booking Dashboard
An interactive railway booking analytics project developed using Microsoft Power BI and an Excel dataset. This project focuses on analyzing railway booking trends, revenue performance, ticket confirmation, passenger distribution, payment methods, and train delays through data analysis and interactive visualizations.
# 🎯 Project Objective
To transform railway booking data into meaningful insights using Excel and Power BI, helping analyze booking patterns, revenue performance, ticket confirmation, passenger distribution, and train delays

# 🛠️ Tools & Skills
- Microsoft Excel
- Microsoft Power BI
- Data Analysis
- Data Visualization
- KPI Development
- Business Intelligence
- Interactive Dashboard Development

# 📊 Project Overview & Core Findings
This project provides a comprehensive view of railway booking performance through an interactive Power BI dashboard featuring KPI cards, booking trends, revenue comparisons, ticket status analysis, and passenger-related metrics.

#Key Insights
- Total Bookings: Analyzed 20,000 railway booking records.
- Total Revenue: ₹5,30,55,565 (approximately ₹5.31 Cr).
- Average Ticket Fare: ₹1,328.08.
- Average Delay: 22.19 minutes.
- Confirmed Tickets: 82.30% of bookings are confirmed.
- Waiting List Tickets:1,192 tickets are on the waiting list.
- Revenue Analysis: Delhi Rajdhani Express generates the highest revenue among the trains analyzed.
- Travel Class Analysis: Compared bookings across CC, 3A, EC, 1A, 2A, and SL classes.
- Payment Analysis:Compared Net Banking, UPI, Credit Card, Debit Card, and IRCTC iMudra/eWallet.
- Train Delay Analysis: Identified the top 10 trains by average delay.

# 🛠️ Tech Stack & Workflow

# 1. Data Source & Preparation — Microsoft Excel
The Excel dataset (`irctc_business_insights.xlsx`) was used as the source for railway booking analysis.

- Reviewed railway booking records and relevant data fields.
- Analyzed booking dates, train names, source and destination stations, and travel classes.
- Examined revenue, ticket status, passenger counts, and train delays.
- Prepared the data for reporting and visualization in Power BI.

 # 2. Data Modeling & Visualization — Power BI
The Excel dataset was imported into Microsoft Power BI to develop an interactive railway booking dashboard.

- Designed a dashboard with a clean and professional layout.
- Created KPI cards for Total Bookings, Total Revenue, Average Ticket Fare, Average Delay, Confirmed Percentage, and Waiting List Tickets.
- Developed a monthly booking trend and a Top 10 Trains by Revenue chart.
- Visualized ticket status distribution and booking status by travel class.
- Created gender-wise passenger count and class-wise booking count charts.
- Analyzed payment methods and the relationship between travel distance and average ticket fare.
- Added interactive slicers to explore booking data across different categories.
